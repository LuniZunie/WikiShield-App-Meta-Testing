## Installation

### Windows
Download the installer directly from the [GitHub Release](https://github.com/LuniZunie/WikiShield-App-Meta-Testing/releases/latest):
- **Download**: `WikiShield-1.0.0-Setup.exe`
- Run the installer and follow the on-screen instructions
- The app will automatically register for updates

### macOS
Download the appropriate installer from the [GitHub Release](https://github.com/LuniZunie/WikiShield-App-Meta-Testing/releases/latest):
- **Intel Macs**: `WikiShield-1.0.0.dmg`
  - Double-click the .dmg file
  - Drag WikiShield to Applications folder

- **Apple Silicon (M1/M2/M3)**: `WikiShield-1.0.0-arm64.dmg`
  - Double-click the .dmg file
  - Drag WikiShield to Applications folder

**Alternative**: If you prefer a zip archive:
- **Intel**: `WikiShield-1.0.0-mac.zip`
- **Apple Silicon**: `WikiShield-1.0.0-arm64-mac.zip`

### Linux
Download the appropriate installer for your distribution from the [GitHub Release](https://github.com/LuniZunie/WikiShield-App-Meta-Testing/releases/latest):

- **Universal (All Distributions)**: `WikiShield-1.0.0.AppImage`
  - `chmod +x WikiShield-1.0.0.AppImage`
  - `./WikiShield-1.0.0.AppImage`

- **Debian/Ubuntu/Linux Mint**: `WikiShield_1.0.0_amd64.deb`
  - `sudo apt install ./WikiShield_1.0.0_amd64.deb`

- **Fedora/RHEL/CentOS**: `WikiShield-1.0.0.x86_64.rpm`
  - `sudo dnf install WikiShield-1.0.0.x86_64.rpm`
  - Or `sudo yum install WikiShield-1.0.0.x86_64.rpm` (older systems)

---

## Auto-Updates
All installers support automatic updates. The app will check for new versions and notify you when an update is available.
